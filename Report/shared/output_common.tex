\subsection{Content of Each Exercise}
For every exercise, the report must contain, in this order:
\begin{enumerate}[itemsep=2pt]
  \item \textbf{Theoretical calculation} -- the laws, formulas and intermediate steps, not only the final values.
  \item \textbf{Schematic} -- a screenshot from LTspice showing component values, net labels and the SPICE directive.
  \item \textbf{Simulation result} -- the waveform window (with cursor or \texttt{.meas} values) or the operating-point values
        from the \textit{SPICE Error Log}, whichever the exercise asks for.
  \item \textbf{Comparison table} -- theory versus simulation, with the percentage error
        \[\varepsilon = \frac{|X_{\mathrm{sim}}-X_{\mathrm{theory}}|}{|X_{\mathrm{theory}}|}\times 100\%\]
  \item \textbf{Comment} -- one to three sentences explaining any deviation (model, assumed $V_D$, $\beta$, \ldots).
\end{enumerate}

\subsection{Figure and Formatting Rules}
\begin{itemize}[itemsep=2pt]
  \item Every figure is captured from LTspice, numbered, captioned and readable when printed in black and white.
        Use a light plot background (\textit{Tools $\rightarrow$ Color Preferences}).
  \item Use the symbols and units of this manual (e.g.\ $V_{CE}$, $I_D$, $1.5\,\mathrm{k\Omega}$); write SPICE values only inside the schematic.
  \item Report only values obtained from your own simulation run; do not copy values from other groups or tools.
  \item The \texttt{.asc} files must open and run on the offline LTspice installation (Appendix~A) without any download.
\end{itemize}
