\chapter*{How to Use This Manual}
\addcontentsline{toc}{chapter}{How to Use This Manual}

This manual replaces the PSpice for TI simulation labs of \courseNameEN\ (\courseCode) with
\textbf{LTspice} (Analog Devices, version \ltspiceVersion). It contains six labs.
Every lab is a chapter \textbf{Lab N} with the same five parts, numbered N.1 to N.5 in the table of contents:
\begin{enumerate}[itemsep=2pt]
  \item \textbf{Introduction} -- objectives and the analysis types introduced;
  \item \textbf{LTspice Guide} -- step-by-step instructions with screenshots;
  \item \textbf{Exercises} -- ten exercises (Ex~N.1 to Ex~N.10), each with circuit, theoretical calculation (left blank for you), simulation setup and a theory-vs-simulation table;
  \item \textbf{Advanced Exercises} -- optional, more challenging tasks (Adv~N.A1, Adv~N.A2);
  \item \textbf{Output Requirements} -- the files to submit, what each exercise must show in the report, and a checklist.
\end{enumerate}

\section*{Conventions}
\begin{itemize}[itemsep=2pt]
  \item Every exercise is tagged \statusbadge{Keep} (only the tool changed), \statusbadge{Adjust} (components/values changed, same objective) or \statusbadge{Replace} (new equivalent exercise).
  \item LTspice files are named \texttt{LabN/ExNN.asc} and \texttt{LabN/AdvNN.asc} and open directly on the offline installation (Appendix~A).
  \item Cells marked \fillcell{} must be filled in by the student.
  \item SPICE directives are shown in grey boxes and are typed on the schematic with \textit{Edit $\rightarrow$ SPICE Directive}.
\end{itemize}
