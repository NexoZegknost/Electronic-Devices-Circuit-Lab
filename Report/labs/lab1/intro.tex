\subsection{Objectives}
After this lab, students will be able to:
\begin{itemize}[itemsep=2pt]
  \item Create, wire and simulate a schematic in LTspice.
  \item Use the \texttt{.op} analysis and read node voltages and branch currents.
  \item Use dependent sources (VCVS, CCVS) to model circuit elements.
  \item Verify KCL/KVL, equivalent resistance, Y--$\Delta$ transformation and power balance by simulation.
\end{itemize}

\subsection{Analysis types introduced}
DC operating point (\texttt{.op}), dependent sources (E, F, G, H), \texttt{.meas}.
