\subsection*{Objectives}
After this lab, students will be able to:
\begin{itemize}[itemsep=2pt]
  \item Use an op-amp model from the LTspice library with a dual supply.
  \item Analyse linear op-amp amplifiers in the time domain.
  \item Plot the frequency response of active filters with an AC sweep.
  \item Observe hysteresis in a Schmitt trigger.
\end{itemize}

\subsection*{Analysis types introduced}
AC sweep (\texttt{.ac}), transient (\texttt{.tran}), \texttt{.meas}.
